---
title: "Manage Cal.com Appointment"
openapi: "POST /api/v1/calcom/appointments/manage"
description: "Book, reschedule, cancel, or check availability for appointments through Cal.com. This endpoint is designed for AI agent use — no API key required, authentication is via `org_id` in the request body."
---

<Note>
  This endpoint does not require the `X-Api-Key` header. Instead, provide the `org_id` in the request body for authentication.
</Note>

### Body

<ParamField body="action" type="string" required>
  The appointment action to perform. Allowed values:
  - `book` — Book a new appointment (requires `name` and either `email` or `phone`).
  - `reschedule` — Reschedule an existing appointment (requires `appointment_id` and `appointment_datetime`).
  - `cancel` — Cancel an existing appointment (requires `appointment_id`).
  - `suggest` — Get suggested available time slots.
  - `availability` — Check all available slots for a date range.
</ParamField>

<ParamField body="agent_id" type="string" required>
  UUID of the AI agent handling the appointment.
</ParamField>

<ParamField body="org_id" type="string" required>
  UUID of your organization — used for authentication instead of an API key.
</ParamField>

<ParamField body="name" type="string">
  Customer's full name. Required when `action` is `book`.
</ParamField>

<ParamField body="email" type="string">
  Customer's email address. Required for `book` if `phone` is not provided.
</ParamField>

<ParamField body="phone" type="string">
  Customer's phone number in E.164 format. Required for `book` if `email` is not provided.
</ParamField>

<ParamField body="appointment_datetime" type="string">
  Desired appointment date and time in ISO 8601 format (e.g. `2026-03-25T14:00:00Z`). Required for `book` and `reschedule`.
</ParamField>

<ParamField body="appointment_id" type="string">
  Existing appointment ID. Required for `cancel` and `reschedule`.
</ParamField>

<ParamField body="call_session_id" type="string">
  Call session ID to associate with the booking (optional, for tracking purposes).
</ParamField>

<ParamField body="notes" type="string">
  Optional notes to attach to the appointment.
</ParamField>

<ParamField body="days_ahead" type="integer">
  Number of days ahead to search for available slots (default: `7`, max: `30`). Used with `suggest` and `availability` actions.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Natural language message suitable for relaying directly to the customer.</ResponseField>
<ResponseField name="data" type="object">
  Appointment result data.

  <Expandable title="data">
    <ResponseField name="success" type="boolean">Whether the appointment action was successful.</ResponseField>
    <ResponseField name="message" type="string">Detailed result message.</ResponseField>
    <ResponseField name="summary" type="string">Short label (e.g. `"Appointment confirmed"`, `"Cancelled"`, `"Rescheduled"`).</ResponseField>
    <ResponseField name="action" type="string">The action that was performed.</ResponseField>
    <ResponseField name="appointment_id" type="string">Appointment ID (returned for `book`, `reschedule`, `cancel`).</ResponseField>
    <ResponseField name="date_time" type="string">Confirmed appointment datetime in ISO 8601 format.</ResponseField>
    <ResponseField name="agent_name" type="string">Name of the agent or calendar owner handling the appointment.</ResponseField>
    <ResponseField name="action_required" type="string">Next action required if the request could not be fully completed (e.g. `"reschedule"`).</ResponseField>
    <ResponseField name="available_slots" type="object[]">
      Available time slots grouped by date.

      <Expandable title="available_slots[]">
        <ResponseField name="date" type="string">Date in `YYYY-MM-DD` format.</ResponseField>
        <ResponseField name="date_label" type="string">Human-readable date label (e.g. `"Today"`, `"Tomorrow"`).</ResponseField>
        <ResponseField name="slots" type="string[]">Array of available time strings (e.g. `["9:00 AM", "11:30 AM"]`).</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
