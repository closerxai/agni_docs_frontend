---
title: "Delete Agent"
description: "Permanently delete a voice AI agent and all its associated configuration. This action cannot be undone."
---

<Warning>
  This action is irreversible. The agent and its configuration will be permanently deleted. If you only want to pause it, use [Update Agent Status](/api-reference/agents/update-status) instead.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the agent to delete.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
