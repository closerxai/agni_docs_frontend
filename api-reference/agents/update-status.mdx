---
title: "Update Agent Status"
openapi: "PATCH /api/v1/agents/{id}/status/"
description: "Activate or deactivate a voice AI agent without modifying its configuration."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the agent whose status you want to change.
</ParamField>

---

### Body

<ParamField body="status" type="string" required>
  New status for the agent. Allowed values:
  - `AGENT_STATUS_ACTIVE` — agent can receive and make calls.
  - `AGENT_STATUS_INACTIVE` — agent is paused and will not handle calls.
  - `AGENT_STATUS_UNSPECIFIED` — reset to default state.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">`null` on success. The status change is confirmed by the `success` field.</ResponseField>

<RequestExample>

```bash cURL
curl -X PATCH https://api.ravan.ai/api/v1/agents/019d1fdb-98e9-7c87-86c7-321e2fa98733/status/ \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"status": "AGENT_STATUS_INACTIVE"}'
```

```python Python
import requests

agent_id = "019d1fdb-98e9-7c87-86c7-321e2fa98733"
response = requests.patch(
    f"https://api.ravan.ai/api/v1/agents/{agent_id}/status/",
    headers={
        "X-Api-Key": "YOUR_API_KEY",
        "Content-Type": "application/json"
    },
    json={"status": "AGENT_STATUS_INACTIVE"}
)
print(response.json())
```
