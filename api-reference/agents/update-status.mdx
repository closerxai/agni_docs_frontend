---
title: "Update Agent Status"
description: "Activate or deactivate a voice AI agent without modifying its configuration."
openapi: "PATCH /api/v1/agents/{id}/status/"
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the agent whose status you want to change.
</ParamField>

---

### Body

<ParamField body="status" type="string" required>
  New status for the agent. Allowed values:
  - `AGENT_STATUS_ACTIVE` — agent can receive and make calls.
  - `AGENT_STATUS_INACTIVE` — agent is paused and will not handle calls.
  - `AGENT_STATUS_UNSPECIFIED` — reset to default state.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">`null` on success. The status change is confirmed by the `success` field.</ResponseField>
