---
title: "Get GHL Agent by Calendar"
openapi: "GET /api/v1/ghl/setup/agents/calendar/{calendar_id}"
description: "Look up which agent is assigned to a specific GHL calendar. Returns the agent details and assignment status."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="calendar_id" type="string" required>
  The GHL calendar ID to look up.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  Agent-calendar assignment details.

  <Expandable title="data">
    <ResponseField name="agent_id" type="string">UUID of the agent assigned to this calendar.</ResponseField>
    <ResponseField name="agent_name" type="string">Display name of the assigned agent.</ResponseField>
    <ResponseField name="calendar_id" type="string">GHL calendar ID.</ResponseField>
    <ResponseField name="is_active" type="boolean">Whether the agent-calendar assignment is active.</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 timestamp of when the assignment was created.</ResponseField>
  </Expandable>
</ResponseField>

