---
title: "Get GHL Appointment"
openapi: "GET /api/v1/ghl/appointments/{appointment_id}"
description: "Retrieve details of a single GHL appointment by its ID, including contact information and current status."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="appointment_id" type="string" required>
  The unique appointment ID to retrieve.
</ParamField>

---

### Query Parameters

<ParamField query="org_id" type="string">Organization ID (optional fallback for authentication).</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  The appointment record.

  <Expandable title="data">
    <ResponseField name="id" type="string">Internal appointment record ID.</ResponseField>
    <ResponseField name="ghl_appointment_id" type="string">GoHighLevel appointment ID.</ResponseField>
    <ResponseField name="contact_id" type="string">GHL contact ID of the customer.</ResponseField>
    <ResponseField name="agent_id" type="string">ID of the agent handling this appointment.</ResponseField>
    <ResponseField name="agent_name" type="string">Name of the agent.</ResponseField>
    <ResponseField name="contact_name" type="string">Customer's full name.</ResponseField>
    <ResponseField name="contact_email" type="string">Customer's email address.</ResponseField>
    <ResponseField name="contact_phone" type="string">Customer's phone number.</ResponseField>
    <ResponseField name="appointment_time" type="string">Appointment datetime in ISO 8601.</ResponseField>
    <ResponseField name="status" type="string">Appointment status.</ResponseField>
  </Expandable>
</ResponseField>
