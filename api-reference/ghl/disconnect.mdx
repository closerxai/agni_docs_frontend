---
title: "Disconnect GHL"
openapi: "POST /api/v1/ghl/disconnect"
description: "Disconnect the GoHighLevel integration from your organization. This revokes OAuth tokens and removes all calendar-agent assignments."
---

<Warning>
  This will disconnect GHL from your organization. All GHL calendar-agent assignments will be removed. You will need to re-authorize via OAuth to reconnect.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">Empty object on success.</ResponseField>
