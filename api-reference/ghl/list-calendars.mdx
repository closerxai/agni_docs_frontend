---
title: "List GHL Calendars"
openapi: "GET /api/v1/ghl/setup/calendars"
description: "Retrieve all calendars available in your connected GoHighLevel account. Use these calendar IDs when configuring agents for appointment scheduling."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  Calendar results.

  <Expandable title="data">
    <ResponseField name="calendars" type="object[]">
      Array of GHL calendars.

      <Expandable title="calendars[]">
        <ResponseField name="id" type="string">GHL calendar ID.</ResponseField>
        <ResponseField name="name" type="string">Calendar name.</ResponseField>
        <ResponseField name="description" type="string">Calendar description.</ResponseField>
        <ResponseField name="locationId" type="string">GHL location ID the calendar belongs to.</ResponseField>
        <ResponseField name="serviceTitle" type="string">Service title associated with this calendar.</ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="count" type="integer">Total number of calendars found.</ResponseField>
  </Expandable>
</ResponseField>
