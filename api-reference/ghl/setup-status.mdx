---
title: "GHL Setup Status"
openapi: "GET /api/v1/ghl/setup/status"
description: "Check the current GoHighLevel integration setup status, including whether GHL is connected, OAuth tokens are valid, and agents have been configured."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  GHL setup status details.

  <Expandable title="data">
    <ResponseField name="ghl_connected" type="boolean">Whether the GoHighLevel OAuth connection is active.</ResponseField>
    <ResponseField name="location_id" type="string">GHL location ID linked to this organization.</ResponseField>
    <ResponseField name="company_id" type="string">GHL company ID linked to this organization.</ResponseField>
    <ResponseField name="token_valid" type="boolean">Whether the OAuth access token is still valid and not expired.</ResponseField>
    <ResponseField name="agents_created" type="boolean">Whether at least one agent has been created with a GHL calendar.</ResponseField>
    <ResponseField name="agent_count" type="integer">Number of agents configured with GHL calendars.</ResponseField>
    <ResponseField name="setup_complete" type="boolean">Whether the full GHL setup is complete and ready to use.</ResponseField>
    <ResponseField name="message" type="string">Human-readable setup status description.</ResponseField>
    <ResponseField name="next_step" type="string">
      Next action to complete the setup:
      - `CONNECT_GHL` — GHL is not connected yet, initiate OAuth.
      - `CREATE_AGENT` — Connected, but no agents have calendars assigned.
      - `""` (empty) — Setup is complete and operational.
    </ResponseField>
  </Expandable>
</ResponseField>
