---
title: "GHL OAuth Callback"
openapi: "GET /api/v1/ghl/oauth/callback"
description: "OAuth callback endpoint that GHL redirects to after the user authorizes access. This completes the OAuth flow and stores the access tokens."
---

<Note>
  This endpoint is called automatically by GoHighLevel after the user authorizes the connection. You do not need to call this endpoint directly.
</Note>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

This endpoint handles the OAuth callback from GoHighLevel. It receives the authorization code, exchanges it for access tokens, and stores the connection. The browser is then redirected to a confirmation page.
