---
title: "Health Check"
openapi: "GET /health"
description: "Check whether the Agni API service is running and responsive. No authentication required."
---

<Note>
  This endpoint does not require authentication. Use it to verify the service is reachable before making authenticated requests.
</Note>

### Response

<ResponseField name="status" type="string">
  Service health status. Returns `"healthy"` when the service is operational.
</ResponseField>

<ResponseField name="service" type="string">
  Name of the service instance responding (e.g. `"integration_service"`).
</ResponseField>

<ResponseField name="time" type="string">
  Current server time in ISO 8601 UTC format.
</ResponseField>

<RequestExample>

```bash cURL
curl https://api.ravan.ai/health
```

```python Python
import requests

response = requests.get("https://api.ravan.ai/health")
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.ravan.ai/health");
const data = await response.json();
console.log(data);
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": "healthy",
  "service": "integration_service",
  "time": "2026-03-20T14:30:00Z"
}
```

</ResponseExample>
