---
title: "Readiness Check"
openapi: "GET /ready"
description: "Check whether the service and all its dependencies (database, cache, etc.) are ready to accept traffic. No authentication required."
---

<Note>
  This endpoint does not require authentication. It returns `200` when the service is fully ready, or `503` when a dependency is unavailable.
</Note>

### Response

<ResponseField name="status" type="string">
  Readiness status — `"ready"` or `"unready"`.
</ResponseField>

<ResponseField name="error" type="string">
  Present only when `status` is `"unready"`. Describes which dependency is failing.
</ResponseField>

<RequestExample>

```bash cURL
curl https://api.ravan.ai/ready
```

```python Python
import requests

response = requests.get("https://api.ravan.ai/ready")
print(response.status_code, response.json())
```

```javascript JavaScript
const response = await fetch("https://api.ravan.ai/ready");
const data = await response.json();
console.log(response.status, data);
```

</RequestExample>

<ResponseExample>

```json 200
{
  "status": "ready"
}
```




```json 503
{
  "status": "unready",
  "error": "database connection failed"
}
```




```json 500
{
  "success": false,
  "message": "Something went wrong on our end",
  "error": {
    "code": "INTERNAL_ERROR",
    "message": "An unexpected error occurred. Please try again later."
  }
}
```




```json 502
{
  "success": false,
  "message": "Service temporarily unavailable",
  "error": {
    "code": "BAD_GATEWAY",
    "message": "Unable to reach upstream service. Please try again."
  }
}
```

</ResponseExample>
