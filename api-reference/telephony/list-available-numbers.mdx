---
title: "List Available Numbers"
openapi: "GET /api/v1/phone-numbers/available-numbers/{iso_country}/"
description: "Browse available phone numbers for purchase in a specific country. Returns numbers with pricing details for both inbound and outbound calls."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="iso_country" type="string" required>
  Two-letter ISO 3166-1 alpha-2 country code (e.g. `US`, `GB`, `IN`, `DE`).
</ParamField>

---

### Query Parameters

<ParamField query="page_size" type="integer">
  Number of available numbers to return. Useful for limiting results when browsing.
</ParamField>

<ParamField query="region" type="string">
  Filter by region or state within the country (e.g. `CA` for California, `TX` for Texas).
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">
  Array of available phone numbers.

  <Expandable title="data[]">
    <ResponseField name="isoCountry" type="string">ISO country code of the phone number.</ResponseField>
    <ResponseField name="phoneNumber" type="string">Phone number in E.164 format (e.g. `+13612738809`).</ResponseField>
    <ResponseField name="price" type="number">Monthly cost of the phone number in USD.</ResponseField>
    <ResponseField name="perMinutePriceOutbound" type="number">Per-minute cost for outbound calls in USD.</ResponseField>
    <ResponseField name="perMinutePriceInbound" type="number">Per-minute cost for inbound calls in USD.</ResponseField>
    <ResponseField name="telephonyType" type="string">Telephony provider type (empty string if using default provider).</ResponseField>
  </Expandable>
</ResponseField>
