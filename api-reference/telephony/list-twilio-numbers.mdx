---
title: "List Twilio Owned Numbers"
openapi: "GET /api/v1/phone-numbers/twilio-owned-numbers/"
description: "List phone numbers from your connected Twilio account that are not yet imported into the Agni platform. Use this to discover numbers available for import."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">
  Array of Twilio phone numbers not yet imported into the platform.

  <Expandable title="data[]">
    <ResponseField name="sid" type="string">Twilio resource SID (unique identifier in Twilio).</ResponseField>
    <ResponseField name="phone_number" type="string">Phone number in E.164 format.</ResponseField>
    <ResponseField name="friendly_name" type="string">Human-readable label set in Twilio.</ResponseField>
    <ResponseField name="status" type="string">Number status in Twilio (e.g. `in-use`, `active`).</ResponseField>
    <ResponseField name="date_created" type="string">Date the number was created in Twilio.</ResponseField>
    <ResponseField name="voice" type="boolean">Whether voice calling capability is enabled.</ResponseField>
    <ResponseField name="sms" type="boolean">Whether SMS capability is enabled.</ResponseField>
    <ResponseField name="mms" type="boolean">Whether MMS capability is enabled.</ResponseField>
  </Expandable>
</ResponseField>
