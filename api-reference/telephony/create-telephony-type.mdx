---
title: "Create Telephony Type"
description: "Register a custom telephony provider (e.g. Twilio, Telnyx, or your own SIP infrastructure) for use with Agni."
---

Use this endpoint to connect your own telephony provider to Agni. Once registered, you can import phone numbers from that provider and use them with your voice agents.

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Body

<ParamField body="type" type="string" required>
  The telephony provider type. Supported values: `twilio`, `telnyx`, `vonage`, `custom`.
</ParamField>

<ParamField body="owner_type" type="string" required>
  Ownership scope — typically `organization`.
</ParamField>

<ParamField body="friendly_name" type="string" required>
  A human-readable label for this telephony configuration (e.g. `"My Twilio Account"`).
</ParamField>

<ParamField body="client_id" type="string">
  Provider API key, Account SID, or equivalent credential identifier.
</ParamField>

<ParamField body="client_secret" type="string">
  Provider Auth Token, API secret, or equivalent secret credential.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  The created telephony configuration.

  <Expandable title="data">
    <ResponseField name="id" type="string">Unique telephony configuration ID.</ResponseField>
    <ResponseField name="type" type="string">Provider type.</ResponseField>
    <ResponseField name="owner_type" type="string">Ownership scope.</ResponseField>
    <ResponseField name="friendly_name" type="string">Display name.</ResponseField>
    <ResponseField name="status" type="string">Configuration status (e.g. `active`).</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 creation timestamp.</ResponseField>
    <ResponseField name="termination_uri" type="string">SIP termination URI (if applicable).</ResponseField>
    <ResponseField name="sip_username" type="string">Generated SIP username (if applicable).</ResponseField>
    <ResponseField name="sip_password" type="string">Generated SIP password (if applicable).</ResponseField>
  </Expandable>
</ResponseField>
