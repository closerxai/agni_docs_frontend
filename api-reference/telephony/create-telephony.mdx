---
title: "Create Telephony Type"
openapi: "POST /api/v1/phone-numbers/create/telephony/"
description: "Register a new telephony provider configuration (e.g. Twilio, Vonage) to use for purchasing and managing phone numbers."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Body

<ParamField body="type" type="string" required>
  Telephony provider type — e.g. `twilio`, `vonage`.
</ParamField>

<ParamField body="owner_type" type="string" required>
  Ownership type — e.g. `organization`, `user`.
</ParamField>

<ParamField body="friendly_name" type="string">
  Human-readable label for this telephony configuration (e.g. `"My Twilio Account"`).
</ParamField>

<ParamField body="client_id" type="string" required>
  Provider account/client ID (e.g. Twilio Account SID).
</ParamField>

<ParamField body="client_secret" type="string" required>
  Provider auth token or client secret (e.g. Twilio Auth Token).
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  The created telephony configuration.

  <Expandable title="data">
    <ResponseField name="id" type="string">Unique telephony configuration ID.</ResponseField>
    <ResponseField name="type" type="string">Provider type (e.g. `twilio`).</ResponseField>
    <ResponseField name="owner_type" type="string">Ownership type.</ResponseField>
    <ResponseField name="friendly_name" type="string">Human-readable label.</ResponseField>
    <ResponseField name="status" type="string">Configuration status (e.g. `active`).</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 creation timestamp.</ResponseField>
    <ResponseField name="termination_uri" type="string">SIP termination URI (auto-generated).</ResponseField>
    <ResponseField name="sip_username" type="string">SIP username (auto-generated).</ResponseField>
    <ResponseField name="sip_password" type="string">SIP password (auto-generated).</ResponseField>
  </Expandable>
</ResponseField>
