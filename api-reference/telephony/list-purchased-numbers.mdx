---
title: "List Purchased Numbers"
openapi: "GET /api/v1/phone-numbers/list"
description: "Retrieve all phone numbers currently owned by your organization, with details about pricing, status, and associated telephony configuration."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Query Parameters

<ParamField query="region" type="string">Filter by region or state.</ParamField>
<ParamField query="iso_country" type="string">Filter by ISO country code (e.g. `US`, `GB`).</ParamField>
<ParamField query="is_active" type="boolean">Filter by active status — `true` for active numbers, `false` for inactive.</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">
  Array of purchased phone number records.

  <Expandable title="data[]">
    <ResponseField name="id" type="string">Unique record ID (UUID).</ResponseField>
    <ResponseField name="telephony_id" type="string">Associated telephony provider configuration ID.</ResponseField>
    <ResponseField name="subscription_id" type="string">Billing subscription ID for this number.</ResponseField>
    <ResponseField name="inbound_trunk_id" type="string">Inbound SIP trunk ID for receiving calls.</ResponseField>
    <ResponseField name="outbound_trunk_id" type="string">Outbound SIP trunk ID for making calls.</ResponseField>
    <ResponseField name="number" type="string">Phone number in E.164 format.</ResponseField>
    <ResponseField name="friendly_name" type="string">Human-readable label for the number.</ResponseField>
    <ResponseField name="per_minute_price_inbound" type="number">Per-minute cost for receiving calls (USD).</ResponseField>
    <ResponseField name="per_minute_price_outbound" type="number">Per-minute cost for making calls (USD).</ResponseField>
    <ResponseField name="price" type="number">Monthly cost of the number (USD).</ResponseField>
    <ResponseField name="region" type="string">Geographic region of the number.</ResponseField>
    <ResponseField name="iso_country" type="string">ISO country code.</ResponseField>
    <ResponseField name="is_active" type="boolean">Whether the number is currently active.</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 timestamp when the number was purchased.</ResponseField>
    <ResponseField name="updated_at" type="string">ISO 8601 timestamp of last update.</ResponseField>
  </Expandable>
</ResponseField>
