---
title: "Delete Imported Number"
openapi: "DELETE /api/v1/phone-numbers/import/{id}"
description: "Remove an imported phone number from the Agni platform. This does not affect the number on your external telephony provider."
---

<Warning>
  This action is irreversible. The imported number will be removed from Agni, and any inbound dispatch rules pointing to it will stop working. Your number on the external provider is not affected.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique ID of the imported phone number to delete.
</ParamField>

---

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
