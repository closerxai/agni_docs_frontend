---
title: "Release Phone Number"
description: "Release a purchased phone number back to the pool. The number will no longer be available for your agents and billing will stop."
---

<Warning>
  This action cannot be undone. Once released, the phone number becomes available to other customers and you may not be able to reclaim it.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="phone_number" type="string" required>
  The phone number to release in E.164 format (e.g. `+13612738809`).
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  Release confirmation.

  <Expandable title="data">
    <ResponseField name="phone_number" type="string">The released phone number.</ResponseField>
    <ResponseField name="status" type="string">Number status after release (e.g. `released`).</ResponseField>
    <ResponseField name="released_at" type="string">ISO 8601 timestamp of release.</ResponseField>
  </Expandable>
</ResponseField>
