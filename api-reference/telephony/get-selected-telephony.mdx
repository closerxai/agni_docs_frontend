---
title: "Get Selected Telephony"
description: "Retrieve the currently active telephony provider configuration for your organization."
openapi: "GET /api/v1/phone-numbers/selected-telephony"
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  The currently selected telephony provider.

  <Expandable title="data">
    <ResponseField name="provider" type="string">Active provider type (e.g. `twilio`, `telnyx`, `custom`).</ResponseField>
    <ResponseField name="owner_type" type="string">Ownership scope (e.g. `organization`).</ResponseField>
    <ResponseField name="last_four_sid" type="string">Last 4 characters of the provider API key / Account SID for identification.</ResponseField>
    <ResponseField name="last_four_auth" type="string">Last 4 characters of the provider Auth Token for identification.</ResponseField>
  </Expandable>
</ResponseField>
