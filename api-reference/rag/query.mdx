---
title: "Query Knowledge Base"
openapi: "POST /api/v1/rag/query"
description: "Run a semantic search query against a knowledge base to retrieve the most relevant document chunks."
---

<Note>This endpoint is used internally by agents during calls. You can also call it directly to test retrieval quality.</Note>

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Body
<ParamField body="org_id" type="string" required>UUID of your organization.</ParamField>
<ParamField body="kb_id" type="string" required>Knowledge base to search.</ParamField>
<ParamField body="query" type="string" required>Natural language question or search query.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">Query results with relevant document chunks and similarity scores.</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.ravan.ai/api/v1/rag/query \
  -H "X-Api-Key: YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"org_id": "1268c1f0-19f3-47db-aefb-c16a7c3ace6e", "kb_id": "product_docs", "query": "What is the pricing per minute?"}'
```

```python Python
import requests
response = requests.post("https://api.ravan.ai/api/v1/rag/query",
    headers={"X-Api-Key": "YOUR_API_KEY"},
    json={"org_id": "1268c1f0-19f3-47db-aefb-c16a7c3ace6e", "kb_id": "product_docs", "query": "What is the pricing per minute?"})
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.ravan.ai/api/v1/rag/query", {
  method: "POST", headers: { "X-Api-Key": "YOUR_API_KEY", "Content-Type": "application/json" },
  body: JSON.stringify({ org_id: "1268c1f0-19f3-47db-aefb-c16a7c3ace6e", kb_id: "product_docs", query: "What is the pricing per minute?" })
});
console.log(await response.json());
```
