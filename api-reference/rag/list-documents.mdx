---
title: "List Documents"
openapi: "GET /api/v1/rag/documents"
description: "List all documents in a specific knowledge base."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Query Parameters
<ParamField query="org_id" type="string" required>UUID of your organization.</ParamField>
<ParamField query="kb_id" type="string" required>Knowledge base identifier.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">Array of document records.</ResponseField>

<RequestExample>

```bash cURL
curl "https://api.ravan.ai/api/v1/rag/documents?org_id=1268c1f0-19f3-47db-aefb-c16a7c3ace6e&kb_id=product_docs" \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.get("https://api.ravan.ai/api/v1/rag/documents",
    headers={"X-Api-Key": "YOUR_API_KEY"},
    params={"org_id": "1268c1f0-19f3-47db-aefb-c16a7c3ace6e", "kb_id": "product_docs"})
print(response.json())
```
