title: "List Knowledge Bases"
openapi: "GET /api/v1/rag/knowledgebases"
description: "List all knowledge bases in your organization."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Query Parameters
<ParamField query="org_id" type="string" required>UUID of your organization.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">Array of knowledge base records.</ResponseField>

<RequestExample>

```bash cURL
curl "https://api.ravan.ai/api/v1/rag/knowledgebases?org_id=1268c1f0-19f3-47db-aefb-c16a7c3ace6e" \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.get("https://api.ravan.ai/api/v1/rag/knowledgebases",
    headers={"X-Api-Key": "YOUR_API_KEY"},
```
