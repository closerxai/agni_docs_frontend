---
title: "Get Document"
openapi: "GET /api/v1/rag/document"
description: "Retrieve a specific document from a knowledge base by its document ID."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Query Parameters
<ParamField query="org_id" type="string" required>UUID of your organization.</ParamField>
<ParamField query="doc_id" type="string" required>The document ID to retrieve.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The document record including content and metadata.</ResponseField>

<RequestExample>

```bash cURL
curl "https://api.ravan.ai/api/v1/rag/document?org_id=1268c1f0-19f3-47db-aefb-c16a7c3ace6e&doc_id=pricing_page" \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.get("https://api.ravan.ai/api/v1/rag/document",
    headers={"X-Api-Key": "YOUR_API_KEY"},
    params={"org_id": "1268c1f0-19f3-47db-aefb-c16a7c3ace6e", "doc_id": "pricing_page"})
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.ravan.ai/api/v1/rag/document?org_id=1268c1f0-19f3-47db-aefb-c16a7c3ace6e&doc_id=pricing_page",
  { headers: { "X-Api-Key": "YOUR_API_KEY" } });
console.log(await response.json());
```
