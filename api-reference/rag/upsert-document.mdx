---
title: "Upsert Document"
openapi: "POST /api/v1/rag/document"
description: "Add or update a document in a knowledge base. Supports raw text, single URL crawling, and batch URL crawling with configurable depth."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Body

<ParamField body="org_id" type="string" required>UUID of your organization.</ParamField>
<ParamField body="kb_id" type="string" required>Knowledge base identifier (e.g. `"product_docs"`, `"help_center"`).</ParamField>
<ParamField body="doc_id" type="string" required>Unique document identifier. If a document with this ID exists, it will be updated.</ParamField>
<ParamField body="text" type="string">Raw text content to ingest. Omit if using `url` or `urls`.</ParamField>
<ParamField body="url" type="string">Single URL to crawl and ingest.</ParamField>
<ParamField body="urls" type="string[]">Array of URLs for batch crawling.</ParamField>
<ParamField body="max_pages" type="integer">Maximum pages to crawl. Default: `500`.</ParamField>
<ParamField body="max_depth" type="integer">Maximum link depth to follow. Default: `5`.</ParamField>
<ParamField body="metadata" type="object">Optional key-value metadata (e.g. `{"category": "pricing"}`).</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The upserted document record.</ResponseField>
