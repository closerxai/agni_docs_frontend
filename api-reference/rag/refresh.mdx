---
title: "Refresh Knowledge Base"
description: "Re-crawl and re-index all documents in a knowledge base to pick up content changes from the original sources."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Body
<ParamField body="org_id" type="string" required>UUID of your organization.</ParamField>
<ParamField body="kb_id" type="string" required>Knowledge base identifier to refresh.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>

```java Java
import java.net.http.*;
import java.net.URI;

HttpClient client = HttpClient.newHttpClient();
String json = "{\"org_id\":\"1268c1f0-19f3-47db-aefb-c16a7c3ace6e\",\"kb_id\":\"product_docs\"}";
HttpRequest request = HttpRequest.newBuilder()
```
