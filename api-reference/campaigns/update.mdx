---
title: "Update Campaign"
description: "Update an existing campaign's name, agent, phone number, or schedule. Only non-empty fields are applied."
openapi: "PATCH /api/v1/campaigns/{id}"
---

<Note>This is a partial update. Only include the fields you want to change.</Note>

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>Campaign UUID.</ParamField>

### Body
<ParamField body="name" type="string">Updated campaign name.</ParamField>
<ParamField body="agent_id" type="string">New agent UUID.</ParamField>
<ParamField body="phone_number_id" type="string">New phone number UUID.</ParamField>
<ParamField body="from_phone_number" type="string">New caller ID (E.164).</ParamField>
<ParamField body="schedule" type="object">Updated scheduling configuration (see [Create Campaign](/api-reference/campaigns/create) for schedule fields).</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The updated campaign object.</ResponseField>
