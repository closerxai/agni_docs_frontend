---
title: "List Campaigns"
description: "List all campaigns in your organization with pagination and optional status filtering."
openapi: "GET /api/v1/campaigns/"
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Query Parameters
<ParamField query="limit" type="integer">Max results per page.</ParamField>
<ParamField query="offset" type="integer">Pagination offset.</ParamField>
<ParamField query="status" type="string">Filter by status: `draft`, `running`, `paused`, `completed`.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">Array of campaign objects.</ResponseField>
<ResponseField name="meta" type="object">Pagination metadata with `total`, `limit`, `offset`.</ResponseField>

<RequestExample>

```bash cURL

  -H "X-Api-Key: YOUR_API_KEY"
```
