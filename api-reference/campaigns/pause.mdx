---
title: "Pause Campaign"
openapi: "POST /api/v1/campaigns/{id}/pause"
description: "Pause a running campaign. Calls currently in progress will complete, but no new calls will be placed."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>Campaign UUID.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The campaign object with `status` set to `paused`.</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.ravan.ai/api/v1/campaigns/019d5b4c-8d9e-0f1a-2b3c-4d5e6f7a8b9c/pause \
  -H "X-Api-Key: YOUR_API_KEY"
```
