---
title: "Add Contacts to Campaign"
openapi: "POST /api/v1/campaigns/{id}/contacts"
description: "Add one or more contacts to an existing campaign. New contacts will be queued as pending."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>Campaign UUID.</ParamField>

### Body
<ParamField body="contact_ids" type="string[]" required>Array of contact UUIDs to add to the campaign.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="added_count" type="integer">Number of contacts successfully added.</ResponseField>

<RequestExample>
