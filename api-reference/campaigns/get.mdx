---
title: "Get Campaign"
description: "Retrieve a single campaign by its ID, including schedule configuration and real-time contact stats."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>Campaign UUID.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The campaign object (see [Create Campaign](/api-reference/campaigns/create) for full schema).</ResponseField>

<RequestExample>

```bash cURL
curl https://api.ravan.ai/api/v1/campaigns/019d5b4c-8d9e-0f1a-2b3c-4d5e6f7a8b9c \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.get("https://api.ravan.ai/api/v1/campaigns/019d5b4c-8d9e-0f1a-2b3c-4d5e6f7a8b9c",
    headers={"X-Api-Key": "YOUR_API_KEY"})
print(response.json())
```
