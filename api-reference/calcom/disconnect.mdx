---
title: "Disconnect Cal.com"
description: "Disconnect a specific Cal.com provider connection from your organization. This revokes the stored API key and removes the scheduling link."
---

<Warning>
  This will disconnect the specified Cal.com connection. Agents using this connection will no longer be able to book appointments through Cal.com.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Body

<ParamField body="org_id" type="string" required>
  UUID of your organization.
</ParamField>

<ParamField body="provider_id" type="string" required>
  UUID of the Cal.com provider connection to disconnect. Retrieve this from the [Connect](/api-reference/calcom/connect) response or [Status](/api-reference/calcom/status) endpoint.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">Empty object on success.</ResponseField>
