---
title: "Connect Cal.com"
description: "Connect your Cal.com account to Agni using an API key. This enables your AI agents to manage appointments through Cal.com calendars."
openapi: "POST /api/v1/calcom/connect"
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Body

<ParamField body="org_id" type="string" required>
  UUID of your organization.
</ParamField>

<ParamField body="api_key" type="string" required>
  Your Cal.com API key (e.g. `cal_live_...`). Generate this from your Cal.com dashboard under **Settings → Developer → API Keys**.
</ParamField>

<ParamField body="account_name" type="string">
  A friendly name for this Cal.com connection (e.g. `"Main Calendar"`).
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">Connection details including the provider ID.</ResponseField>
