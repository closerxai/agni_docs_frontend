---
title: "Cal.com OAuth Connect"
openapi: "GET /api/v1/calcom/oauth/connect"
description: "Initiate the Cal.com OAuth connection flow. This endpoint redirects the browser to Cal.com's consent page — it does not return a JSON response."
---

<Note>
  This is a browser redirect endpoint. Open this URL in a browser to start the Cal.com OAuth flow. It does not return a JSON response.
</Note>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Query Parameters

<ParamField query="organization_id" type="string" required>
  Your organization ID. The Cal.com connection will be linked to this organization.
</ParamField>

---

This endpoint redirects the browser to Cal.com's OAuth consent page. After the user authorizes access, Cal.com redirects back to the [OAuth Callback](/api-reference/calcom/oauth-callback) endpoint to complete the connection.

<RequestExample>

```bash cURL
# Open in browser — this is a redirect, not a JSON API call
curl -v "https://api.ravan.ai/api/v1/calcom/oauth/connect?organization_id=1268c1f0-19f3-47db-aefb-c16a7c3ace6e" \
  -H "X-Api-Key: YOUR_API_KEY"
```

</RequestExample>
