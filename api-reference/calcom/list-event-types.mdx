---
title: "List Cal.com Event Types"
description: "Retrieve all event types configured in your connected Cal.com account. Event types define the scheduling options available for booking (e.g. consultation calls, demos)."
---

<Note>
  Requires an active Cal.com connection. Use the [Cal.com Status](/api-reference/calcom/status) endpoint to verify your connection before calling this endpoint.
</Note>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">
  Array of Cal.com event types.

  <Expandable title="data[]">
    <ResponseField name="id" type="string">Cal.com event type ID.</ResponseField>
    <ResponseField name="slug" type="string">URL slug for the event type (e.g. `intro-call`, `30-min-demo`).</ResponseField>
    <ResponseField name="title" type="string">Display title of the event type.</ResponseField>
    <ResponseField name="description" type="string">Description of what this event type is for.</ResponseField>
    <ResponseField name="duration_minutes" type="integer">Default duration of the event in minutes.</ResponseField>
    <ResponseField name="price" type="number">Price for the event (0 if free).</ResponseField>
    <ResponseField name="currency" type="string">Currency code for the price (e.g. `USD`, `EUR`).</ResponseField>
    <ResponseField name="is_active" type="boolean">Whether this event type is currently accepting bookings.</ResponseField>
  </Expandable>
</ResponseField>
