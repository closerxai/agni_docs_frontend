---
title: "Cal.com Connection Status"
description: "Check whether Cal.com is connected to your organization and whether the API key is still valid."
openapi: "GET /api/v1/calcom/status"
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Query Parameters

<ParamField query="org_id" type="string" required>
  UUID of your organization.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">
  Connection status details.

  <Expandable title="data">
    <ResponseField name="connected" type="boolean">Whether Cal.com is currently connected.</ResponseField>
    <ResponseField name="status" type="string">Connection status — `"active"` when connected, `"not_connected"` otherwise.</ResponseField>
    <ResponseField name="accounts" type="object[]">Array of connected Cal.com accounts (empty when not connected).</ResponseField>
    <ResponseField name="token_expires" type="string">OAuth token expiry timestamp in ISO 8601 (only when connected).</ResponseField>
    <ResponseField name="error" type="string">Error description if the connection has issues.</ResponseField>
    <ResponseField name="message" type="string">Additional context message (e.g. `"Cal.com is not connected"`).</ResponseField>
  </Expandable>
</ResponseField>
