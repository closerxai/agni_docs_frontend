---
title: "Create Agent Tool"
description: "Create a new custom tool (function or webhook) that agents can invoke during calls to perform actions like looking up data, booking appointments, or triggering external workflows."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Body

<ParamField body="name" type="string" required>
  Tool name. Must be a valid function name — use lowercase letters, numbers, and underscores only (e.g. `check_order_status`). No spaces allowed.
</ParamField>

<ParamField body="description" type="string" required>
  Human-readable description of what the tool does. The LLM uses this to decide when to call the tool, so be specific (e.g. "Look up the shipping status of a customer order by order ID").
</ParamField>

<ParamField body="type" type="string" required>
  Tool type. Supported values: `function`, `webhook`.
</ParamField>

<ParamField body="definition" type="object" required>
  Tool definition following the OpenAI function calling schema. Must include `name`, `description`, and `parameters` (JSON Schema format).

  ```json Example
  {
    "name": "check_order_status",
    "description": "Look up the current status of a customer order",
    "parameters": {
      "type": "object",
      "properties": {
        "order_id": {
          "type": "string",
          "description": "The unique order identifier"
        }
      },
      "required": ["order_id"]
    }
  }
  ```
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable status message.
</ResponseField>

<ResponseField name="data" type="object">
  The newly created tool object.

  <Expandable title="data">
    <ResponseField name="id" type="string">Unique tool ID (UUID) assigned by the server.</ResponseField>
    <ResponseField name="organization_id" type="string">Organization ID.</ResponseField>
    <ResponseField name="name" type="string">Tool name.</ResponseField>
    <ResponseField name="description" type="string">Tool description.</ResponseField>
    <ResponseField name="type" type="string">Tool type.</ResponseField>
    <ResponseField name="definition" type="object">Tool definition schema.</ResponseField>
    <ResponseField name="is_active" type="boolean">Whether the tool is active (defaults to `false` on creation).</ResponseField>
  </Expandable>
</ResponseField>
