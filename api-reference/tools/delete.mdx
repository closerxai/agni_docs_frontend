---
title: "Delete Agent Tool"
description: "Permanently delete an agent tool. Any agents using this tool will no longer be able to invoke it."
openapi: "DELETE /api/v1/tools/{id}/"
---

<Warning>
  This action is irreversible. The tool will be permanently removed. Any agents that reference this tool will lose access to it.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [support@ravan.ai](mailto:support@ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the tool to delete.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable status message.
</ResponseField>
