---
title: "Delete Agent Tool"
openapi: "DELETE /api/v1/tools/{id}/"
description: "Permanently delete an agent tool. Any agents using this tool will no longer be able to invoke it."
---

<Warning>
  This action is irreversible. The tool will be permanently removed. Any agents that reference this tool will lose access to it.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the tool to delete.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable status message.
</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE https://api.ravan.ai/api/v1/tools/019d1fdb-3977-7bd5-ab27-8d3b37ddf4fc/ \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests

tool_id = "019d1fdb-3977-7bd5-ab27-8d3b37ddf4fc"

    f"https://api.ravan.ai/api/v1/tools/{tool_id}/",
    headers={"X-Api-Key": "YOUR_API_KEY"}
)
print(response.json())
```
