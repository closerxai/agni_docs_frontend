---
title: "List Widget Settings"
openapi: "GET /api/v1/widget-settings/"
description: "Retrieve all widget configurations in your organization. Each widget settings object defines the appearance and behavior of an embeddable voice chat widget."
---

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">
  Whether the request succeeded.
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable status message.
</ResponseField>

<ResponseField name="data" type="object[]">
  Array of widget settings objects.

  <Expandable title="data[]">
    <ResponseField name="id" type="string">Unique widget settings ID (UUID).</ResponseField>
    <ResponseField name="bot_name" type="string">Display name of the bot shown in the widget header.</ResponseField>
    <ResponseField name="bot_auto_start" type="boolean">Whether the widget automatically starts a conversation when the page loads.</ResponseField>
    <ResponseField name="bot_position" type="string">Widget position on the page. Values: `BOT_POSITION_BOTTOM_RIGHT`, `BOT_POSITION_BOTTOM_LEFT`, `BOT_POSITION_TOP_RIGHT`, `BOT_POSITION_TOP_LEFT`, `BOT_POSITION_UNSPECIFIED`.</ResponseField>
    <ResponseField name="bot_logo" type="string">URL of the bot avatar image displayed in the widget.</ResponseField>
    <ResponseField name="svg_logo" type="string">Inline SVG markup for the widget icon button.</ResponseField>
    <ResponseField name="custom_form_fields" type="object">Custom form fields shown to the user before starting a conversation (e.g. name, email, phone).</ResponseField>
    <ResponseField name="theme" type="object">Widget color theme and styling configuration.</ResponseField>
    <ResponseField name="language" type="string">Language code for widget UI text (e.g. `en`, `es`, `fr`).</ResponseField>
    <ResponseField name="consent_content" type="string">Body text of the consent/privacy modal shown before recording.</ResponseField>
    <ResponseField name="consent_title" type="string">Title of the consent/privacy modal.</ResponseField>
    <ResponseField name="is_active" type="boolean">Whether these widget settings are currently active.</ResponseField>
    <ResponseField name="created_at" type="string">ISO 8601 timestamp when the settings were created.</ResponseField>
    <ResponseField name="updated_at" type="string">ISO 8601 timestamp when the settings were last modified.</ResponseField>
  </Expandable>
</ResponseField>
