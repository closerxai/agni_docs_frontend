---
title: "Deactivate Widget Settings"
openapi: "DELETE /api/v1/widget-settings/{id}/"
description: "Deactivate a widget configuration. The widget will stop appearing on your website, and any agents linked to it will no longer be accessible through the widget."
---

<Warning>
  This deactivates the widget settings. Agents associated with this widget will no longer be reachable via the web widget. Use [Update Widget Settings](/api-reference/widget-settings/update) if you only want to change individual fields.
</Warning>

### Authorizations

<ParamField header="X-Api-Key" type="string" required>
  Your Agni API key. Find it in your [Ravan.ai Dashboard](https://app.ravan.ai) under **Settings → API Keys**.
</ParamField>

---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique UUID of the widget settings to deactivate.
</ParamField>

---

### Response

<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
