---
title: "Get Contact Detail"
openapi: "GET /api/v1/contacts/{id}/detail"
description: "Retrieve the full enriched profile for a contact, including stats, associated campaigns, and activity summary."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>UUID of the contact.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">Full contact profile with stats and campaign associations.</ResponseField>

<RequestExample>

```bash cURL
curl https://api.ravan.ai/api/v1/contacts/019d3a2b-5c6d-7e8f-9a0b-1c2d3e4f5a6b/detail \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.get("https://api.ravan.ai/api/v1/contacts/019d3a2b-5c6d-7e8f-9a0b-1c2d3e4f5a6b/detail", headers={"X-Api-Key": "YOUR_API_KEY"})
print(response.json())
```
