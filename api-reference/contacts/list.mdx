---
title: "List Contacts"
openapi: "GET /api/v1/contacts/"
description: "Search and list contacts in your organization with optional filtering and pagination."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Query Parameters
<ParamField query="search" type="string">Search by name, email, or phone.</ParamField>
<ParamField query="limit" type="integer">Maximum contacts to return.</ParamField>
<ParamField query="offset" type="integer">Pagination offset.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">Array of contact records.</ResponseField>
<ResponseField name="meta" type="object">Pagination metadata with `total`, `limit`, `offset`.</ResponseField>

<RequestExample>

```bash cURL
curl "https://api.ravan.ai/api/v1/contacts/?search=john&limit=10" \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.get("https://api.ravan.ai/api/v1/contacts/", headers={"X-Api-Key": "YOUR_API_KEY"}, params={"search": "john", "limit": 10})
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.ravan.ai/api/v1/contacts/?search=john&limit=10", { headers: { "X-Api-Key": "YOUR_API_KEY" } });
console.log(await response.json());
```
