---
title: "Get Contact Activities"
openapi: "GET /api/v1/contacts/{id}/activities"
description: "Retrieve the activity timeline for a contact -- calls, appointments, campaigns, and notes in chronological order."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>UUID of the contact.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object[]">Array of activity records ordered by timestamp.</ResponseField>

