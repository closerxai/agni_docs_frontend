---
title: "Delete Contact"
openapi: "DELETE /api/v1/contacts/{id}"
description: "Permanently delete a single contact from your organization."
---

<Warning>This action is irreversible.</Warning>

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>UUID of the contact to delete.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE https://api.ravan.ai/api/v1/contacts/019d3a2b-5c6d-7e8f-9a0b-1c2d3e4f5a6b \
  -H "X-Api-Key: YOUR_API_KEY"
```

```python Python
import requests
response = requests.delete("https://api.ravan.ai/api/v1/contacts/019d3a2b-5c6d-7e8f-9a0b-1c2d3e4f5a6b", headers={"X-Api-Key": "YOUR_API_KEY"})
print(response.json())
```
