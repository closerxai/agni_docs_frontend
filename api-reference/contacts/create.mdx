---
title: "Create Contact"
openapi: "POST /api/v1/contacts/"
description: "Create a new contact in your organization's CRM. Contacts are linked to call sessions, campaigns, and appointments."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Body
<ParamField body="first_name" type="string">Contact's first name.</ParamField>
<ParamField body="last_name" type="string">Contact's last name.</ParamField>
<ParamField body="email" type="string">Contact's email address.</ParamField>
<ParamField body="phone" type="string">Phone number in E.164 format.</ParamField>
<ParamField body="company" type="string">Company or organization name.</ParamField>
<ParamField body="metadata" type="object">Optional key-value metadata.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The created contact record.</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.ravan.ai/api/v1/contacts/ \
  -H "X-Api-Key: YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"first_name": "John", "last_name": "Smith", "email": "john@example.com", "phone": "+14155550100", "company": "Acme Corp"}'
```

```python Python
import requests
response = requests.post("https://api.ravan.ai/api/v1/contacts/",
    headers={"X-Api-Key": "YOUR_API_KEY", "Content-Type": "application/json"},
    json={"first_name": "John", "last_name": "Smith", "email": "john@example.com", "phone": "+14155550100", "company": "Acme Corp"})
print(response.json())
```

```javascript JavaScript
const response = await fetch("https://api.ravan.ai/api/v1/contacts/", {
  method: "POST", headers: { "X-Api-Key": "YOUR_API_KEY", "Content-Type": "application/json" },
  body: JSON.stringify({ first_name: "John", last_name: "Smith", email: "john@example.com", phone: "+14155550100", company: "Acme Corp" })
});
console.log(await response.json());
```
