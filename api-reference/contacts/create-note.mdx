---
title: "Create Contact Note"
openapi: "POST /api/v1/contacts/{id}/notes"
description: "Add a note to a contact's profile. Notes appear in the contact's activity timeline."
---

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Path Parameters
<ParamField path="id" type="string" required>UUID of the contact.</ParamField>

### Body
<ParamField body="content" type="string" required>The note text to add.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">The created note record.</ResponseField>

<RequestExample>

```bash cURL
curl -X POST https://api.ravan.ai/api/v1/contacts/019d3a2b-5c6d-7e8f-9a0b-1c2d3e4f5a6b/notes \
  -H "X-Api-Key: YOUR_API_KEY" -H "Content-Type: application/json" \
  -d '{"content": "Interested in enterprise plan. Follow up after demo."}'
```

```python Python
import requests
response = requests.post("https://api.ravan.ai/api/v1/contacts/019d3a2b-5c6d-7e8f-9a0b-1c2d3e4f5a6b/notes",
    headers={"X-Api-Key": "YOUR_API_KEY", "Content-Type": "application/json"},
    json={"content": "Interested in enterprise plan. Follow up after demo."})
print(response.json())
```

