---
title: "Bulk Delete Contacts"
description: "Delete multiple contacts at once by providing an array of contact IDs."
---

<Warning>This action is irreversible. All specified contacts will be permanently removed.</Warning>

### Authorizations
<ParamField header="X-Api-Key" type="string" required>Your Agni API key.</ParamField>

### Body
<ParamField body="ids" type="string[]" required>Array of contact UUIDs to delete.</ParamField>

### Response
<ResponseField name="success" type="boolean">Whether the request succeeded.</ResponseField>
<ResponseField name="message" type="string">Human-readable status message.</ResponseField>
<ResponseField name="data" type="object">Deletion result with count.</ResponseField>
